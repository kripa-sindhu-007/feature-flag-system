# Support

Thanks for using FlagPlane! Here's how to get help.

## Before you ask

- Read the **[README](README.md)** — setup, architecture, API reference, and the
  in-app self-explaining dashboard (take the guided tour at http://localhost:3000).
- Browse the docs in **[`docs/`](docs)**: [BENCHMARKS.md](docs/BENCHMARKS.md),
  [CHAOS.md](docs/CHAOS.md), and [LIMITATIONS.md](docs/LIMITATIONS.md) (guarantees +
  known limitations).
- Search **[existing issues](https://github.com/kripa-sindhu-007/feature-flag-system/issues?q=is%3Aissue)**
  — your question may already be answered.

## Getting help

- **Questions & ideas** — open a
  [Discussion](https://github.com/kripa-sindhu-007/feature-flag-system/discussions)
  (if enabled) or a [feature request](https://github.com/kripa-sindhu-007/feature-flag-system/issues/new/choose).
- **Bugs** — open a [bug report](https://github.com/kripa-sindhu-007/feature-flag-system/issues/new/choose)
  with steps to reproduce.
- **Security issues** — do **not** open a public issue; follow [SECURITY.md](SECURITY.md).

## Good to know

This is a solo-maintained, open-source project — responses are best-effort. Clear,
reproducible reports (versions/commit, steps, logs) get resolved fastest. Pull
requests are always welcome; see [CONTRIBUTING.md](CONTRIBUTING.md).
